# My Launcher

A simple Android home-screen launcher: clock, date, weather, Google search bar,
real Android widgets (including Google's), a dock, and a searchable app drawer.

## Get the APK with no installs (GitHub)
1. Create a free GitHub account and a new repository.
2. Upload everything in this folder (keep the `.github` folder).
3. Open the **Actions** tab -> **Build APK** -> wait ~3-5 min for the green check.
4. Open the run, download **MyLauncher-apk** (a zip containing app-debug.apk).

## Or build with Android Studio
Open this folder in Android Studio -> Build -> Build APK(s).

## Install
1. Copy app-debug.apk to your phone and open it (allow "install unknown apps").
2. Press Home -> choose **My Launcher** -> **Always**.
   (Or Settings -> Apps -> Default apps -> Home app.)

## Using it
- Swipe up from the bottom or tap **Apps** for the app drawer; type to search.
- Long-press an app in the drawer for App info / Uninstall.
- **+ Add widget** lists every widget on your phone (Google search, Clock, etc.).
- Long-press a widget to remove it.
- Weather uses your approximate location (Open-Meteo, no account needed).
